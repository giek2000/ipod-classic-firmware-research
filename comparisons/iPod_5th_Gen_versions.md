# iPod 5th Generation — Version Comparison (5G / 5G Late / 5.5G)

## Overview

The iPod 5th Generation Video shipped across three hardware revisions:
- **5G** (FamilyID 13) — Original 30/60GB (Sep 2005)
- **5G Late 2006** (FamilyID 20) — Revised 30/80GB (Sep 2006)
- **5.5G Enhanced** (FamilyID 25) — Search & brighter screen (Sep 2006)

## Notable Observations

- The 5G (FamilyID 13) and 5G Late (FamilyID 20) firmware versions 1.2.1 produce identical binaries in terms of size and string count
- The 5.5G Enhanced (FamilyID 25) has slightly different binary sizes across versions, indicating actual code changes
- All variants support the same feature set (MeCCA, Games, USB Audio, etc.)
- The firmware version suffix (.1.2.1, .1.2.3, .1.3) represents minor updates within each hardware variant
