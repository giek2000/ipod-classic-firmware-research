# iPod 4th Generation — Mono vs Color/Photo Comparison

## Overview

The iPod 4th Generation shipped in three variants: Mono (grayscale), Color, and Photo. The Color and Photo are essentially identical firmware.

## Key Differences

| Metric | 4th Gen Mono | 4th Gen Color/Photo |
|--------|-------------|--------------------|
| Binary Size | 4,605,440 bytes | 6,514,176 bytes |
| Strings | 10,743 | 12,965 |
| Functions | 7,824 | 9,777 |
| Photos Support | ❌ | ✅ |
| Display | Grayscale | 65,536-color |

## Identical Binaries

The two Mono firmware files (FamilyID 4 and FamilyID 10) are byte-for-byte identical. Apple shipped the same binary for both 20GB and 40GB models.

Similarly, the Color (unnamed), Color (FamilyID 11), and Photo (FamilyID 5) firmwares are all identical — confirming the iPod Photo was just a rebranded iPod Color with no firmware differences.
